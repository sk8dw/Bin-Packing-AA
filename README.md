# Bin-Packing
## A.A. project

Arhiva contine raportul in root. Directorul de surse src contine implementarile pentru algoritmi, codul pentru generarea de teste, un demo de main si codul pentru benchmarking. In directorul src se gaseste si raportul despre alegerea si construirea testelor sub numele de README.md. Folderul test contine 3 directoare cu categorii de teste folosite. Testele din directoare sunt cele care au fost folosite pentru benchmarking. Pentru a rula programul de benchmark, trebuie urmaite instructiunile de descarcare, construire si linkare a bibliotecii benchmark de la google(https://github.com/google/benchmark/). Makefile-ul curent presupune un sistem de operate windows, cu biblioteca salvata in directorul src sub numele de director benchmark, iar biblioteca construita se alfa in directorul cu numele benchmark/build_mingw/src. Un utilizator care foloseste un alt compilator, nume de folder sau a salvat folderul benchmark in alta parte decat directorul src al proiectului va trebui sa modifice Makefile-ul astfel incat sa includa calea corecta catre biblioteca.
